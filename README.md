# ROOM LAB · 동탄2 A105 36A

도면 치수를 기준으로 만든 3D 가구 배치 시뮬레이터입니다. 별도 설치, API 키, npm 빌드가 필요 없는 정적 HTML/JS입니다.

## 파일
- index.html: 화면과 CSS
- app.js: 3D/평면 모델, 가구 편집, 충돌 확인, 저장 및 OBJ 내보내기
- floorplan.jpg: 첨부 원본 도면
- example-layout.json: 침대·책상·소파·테이블 예시 배치. 앱에서 불러올 수 있습니다.
- example-model.obj: 동일 예시 배치의 3D 기본 메시. Blender 등에서 가져올 수 있습니다.
- .nojekyll: 정적 파일 제공 설정

## 실행
모든 파일을 같은 폴더에 두고 index.html을 브라우저로 엽니다. 파일 주소에서 자동 저장이 제한될 수 있으므로 배치 저장(JSON)도 사용하세요.
Python이 설치돼 있다면 이 폴더에서 `python -m http.server 8000`을 실행하고 http://localhost:8000 에서 열 수 있습니다.

## GitHub Pages
1. ZIP을 풀고 내부 파일을 저장소의 최상위에 업로드합니다. ZIP 자체를 올리는 방식이 아닙니다.
2. Settings → Pages → Source: Deploy from a branch → main / (root) → Save.
3. 배포 완료 후 Pages에 표시되는 주소를 엽니다.
기존 저장소의 브랜치 이름이 main이 아니면 해당 기본 브랜치를 선택합니다.
공식 안내: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## 사용
- 3D: 드래그 회전, 휠 또는 +/- 확대. 기본 상태는 실내가 보이도록 벽·창을 낮게 표시합니다.
- 평면: 가구 클릭 및 드래그. 오른쪽에서 가로·깊이·높이(mm), 중심 X/Y, 90도 회전을 지정할 수 있습니다.
- 예시 배치 적용: 가구 크기와 공간을 빠르게 비교합니다. 실제 추천 배치를 의미하지 않습니다.
- 배치 저장/불러오기: 동탄 36A 전용 JSON. 이전 다른 방 모델의 JSON은 호환되지 않습니다.
- 자동 저장은 브라우저와 사이트 주소별입니다. 사이트를 옮길 때는 JSON으로 내보내고 불러오세요.
- 왼쪽 '모델 내보내기 / 배치 불러오기' → '3D 모델 OBJ 내보내기'에서 현재 배치를 3D 메시로 저장합니다.

## 치수 기준과 한계
- 방향: 첨부 도면 방향 그대로. 좌우 반전하지 않았습니다.
- 외곽: 6,810 × 8,385mm.
- 도면의 명시 치수 우선: 상단 작은 방 폭 2,100 / 깊이 2,300; 현관 가로 구간 2,440; 거실 가로 3,290 / 세로 5,110; 침실 가로 3,000 / 세로 3,700; 우측 세로 구간 1,220 / 1,000 / 1,130mm.
- 외곽 치수와 내부 구간의 기준점이 다르므로 단순 합계로 방 면적이나 내측 총 길이를 확정하면 안 됩니다. 창/문/벽 위치의 나머지 구간은 이미지 비례 추정입니다.
- 높이 기본 2,400mm, 조리대 깊이 기본 600mm는 추정값이며 앱에서 수정 가능합니다.
- 욕실 기구, 신발장, 붙박이장, 창호 높이/폭, 문 개방 방향, 구조체 돌출은 도면 이미지를 따른 단순화 및 추정 모델입니다.
- 문 개방 부채꼴은 참고선입니다. 충돌 검사는 벽·고정 공간·이동 가구의 평면 겹침과 모델 천장 높이만 확인합니다. 문 작동이나 실제 통행 가능성은 자동 판정하지 않습니다.
- OBJ는 색상/텍스처 없는 기본 메시이며 단위 m, Y가 높이 방향입니다. 창·벽은 전체 높이로 내보냅니다. 설계용 BIM/CAD 모델은 아닙니다.
- 실제 가구 구매/설치 전 주요 내측 거리와 개구부를 실측하세요.
